Proyecto realizado por Andrea Llanes durante el curso de Back-End Node JS
Cree el directorio pre_entrega_node
Dentro del directorio cree un archivo index.js
Use npm-init 
Cambie la propiedad "type": "module" para habilitar ESModules
Configure el script start para ejecutar el programa con npm run start mediante node index.js

Implemente las siguientes acciones:
          * Consultar Todos los Productos
          * Consultar un Producto Específico
          * Crear un Producto Nuevo
          * Eliminar un Producto
